## 4.1.0

- [新規] Bot メッセージ下部のインタラクションパネルを再構築し、プレフィル進捗・プレフィル/デコード速度・メッセージ/会話 Token などの実行情報表示を追加しました
- [新規] 会話 Token 超過リマインダーを追加しました。現在の会話が 8,000 tokens を超えると、新しい会話の開始を案内し、上部の入口を強調表示します
- [改善] メッセージ領域の操作ボタン配置と余白を最適化し、コピー/共有/再生成/続行生成などの操作をより集約して分かりやすくしました
- [改善] 分岐切り替えのフィードバックとツールチップ文言を改善し、分岐の閲覧操作をより直感的にしました
- [改善] 入力バー・メッセージバブル・下部ステータス領域の表示ディテールを調整し、読みやすさと操作性を向上しました
- [修正] ステートパネルとログパネルの表示/更新フローを修正・最適化し、異常表示の発生を低減しました
- [修正] いくつかの UI 細部の問題を修正しました
