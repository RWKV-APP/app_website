## 4.9.2

- [修正] iPhone と macOS で大きなモデルを解凍するとアプリが終了することがある問題を修正しました。
- [修正] macOS のインストール画面に「アプリケーション」へのショートカットを復元しました。

## 4.9.1

- [新規] チャットで利用できるウェブ検索サービスが増え、入力欄の横で検索の有効化やサービスの切り替えができます。
- [改善] 回答の出典リンクを開いたり、検索の詳細を展開して検索語や結果を確認したりできます。
- [改善] モデル一覧の G1 世代ラベルを見やすくし、バージョンを区別しやすくしました。

## 4.9.0

- [改善] macOS で一部モデルの生成と長いプロンプトの処理を高速化。
- [改善] Windows の CPU 推論性能と CUDA の動作安定性を改善。
- [改善] 一部の Android デバイスで CPU による生成を高速化し、モデル切り替え時のリソース解放を改善。
- [改善] 生成中の不要な画面更新を減らし、操作をよりスムーズに。
- [修正] モデル読み込み後、画面のサンプリング設定と実際の生成パラメーターが一致しない問題を修正。
