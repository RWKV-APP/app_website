## 4.8.0

- [修正] Windows、Linux、Android 向けの 4.8.0（ビルド 755）チャット修正版を再公開しました。以前の 4.8.0 をインストール済みの場合は、ダウンロードページから最新版を再ダウンロードしてインストールしてください
- [修正] G1j 2.9B の通常 GGUF モデルを Q8_0 ウェイトに変更し、従来の Q4 で質問を繰り返す問題に対応しました。モデル一覧から Q8_0 と表示された版をダウンロードしてください
- [修正] Huawei DroiTong で大きなモデルを切り替える際に終了する問題と、長い会話後のログ読み取りでチャットが中断する問題を修正しました
- [修正] Windows、Linux、Android のテキストチャットで思考終了マーカーを正しく認識できず、高速思考モードの回答本文が表示されない問題を修正しました
- [修正] G1j 1.5B と 2.9B の PALM CPU モデルを W8 ウェイトに変更し、従来の W4 で質問を繰り返す、正常に回答できない問題に対応しました。インストール後、モデル一覧から PALM モデルを再ダウンロードしてください

- [修正] [Android 4.8.0 チャット修正版をダウンロード（Huawei DroiTong 対応）](https://modelscope.cn/datasets/HaloWang1991/rwkv-chat/resolve/8f100f24620e128a41c314a39ed97b5954488a12/android-arm64/rwkv_chat_4.8.0_755.apk)

- [新規] RWKV7-G1j 1.5B と 2.9B モデルに対応。互換性のある重みを ModelScope からダウンロードできます
- [新規] PALM CPU 推論バックエンドを追加
- [改善] 現在のデバイスのランタイムが対応する推論バックエンドを表示
