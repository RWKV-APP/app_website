## 4.8.0

- [New] Published 4.8.0 packages (build 755) for Android, Windows (x64 / ARM64), and Linux through Hugging Face, ModelScope, and GitHub; if you installed an earlier 4.8.0 package, download and install the updated package
- [Improved] G1j GGUF keeps the selected quantization: Q6_K for 1.5B and Q4_K_M for 2.9B, 7.2B, and 13.3B
- [Fix] Fixed exits when switching large models in Huawei DroiTong and chat interruptions when reading logs after long conversations
- [Fix] Fixed incomplete thinking end marker recognition and missing Fast-mode answers in Android text chat
- [Fix] G1j 1.5B and 2.9B PALM CPU models now use W8 weights to address prompt echoing and unusable answers with the previous W4 path; download the PALM models again from the model list after installing

- [Fix] [Download the Android 4.8.0 chat repair APK (including Huawei DroiTong)](https://modelscope.cn/datasets/HaloWang1991/rwkv-chat/resolve/8f100f24620e128a41c314a39ed97b5954488a12/android-arm64/rwkv_chat_4.8.0_755.apk)

- [New] Added support for RWKV7-G1j 1.5B, 2.9B, 7.2B, and 13.3B; available models and download sources are shown in the current device's model list
- [New] Added the PALM CPU inference backend
- [Improved] Show inference backends supported by the current device runtime
