## 4.3.0

- [New] Added a local OpenAI-compatible API server that lets you connect RWKV models via the standard API (Windows / macOS / Linux only)
- [New] The API server includes a built-in control panel where you can view request logs, run conversation tests, and browse API documentation
- [New] Added Snapdragon 8 Gen 5 (Snapdragon 8gen5) NPU acceleration support
- [New] Added QNN backend support for RWKV7-G1e 2.9B weights
- [Improved] Expanded and refined the preset prompts (currently Simplified Chinese only; other languages will be added gradually)
- [Improved] Improved the UI presentation of preset prompts
