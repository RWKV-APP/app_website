## 4.2.0

- [New] Added `RWKV Asks for You`: based on the current chat context and a question prefix, it can automatically generate one or more ready-to-send questions
- [New] `RWKV Asks for You` supports multilingual question prefixes and batch generation, helping you start conversations more quickly
- [New] Added MLX weight support for RWKV7-G1e 7.2B on macOS
- [Improved] Refactored remote config and network request URL building, making update info, release notes, and suggestion fetching more stable
- [Improved] Adjusted the input bar interaction structure and improved the visual presentation of the suggestion areas in image and voice pages
- [Improved] On mobile, the screen now stays awake automatically while the model is generating replies or downloading weights, reducing task interruptions
- [Fix] Fixed an issue where some page information could be displayed repeatedly
- [Fix] Fixed several minor UI issues
