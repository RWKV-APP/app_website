## 4.1.0

- [New] Rebuilt the Bot message bottom interaction panel, adding runtime details such as prefill progress, prefill/decode speed, and message/conversation token metrics
- [New] Added a conversation token limit reminder: when the current conversation exceeds 8,000 tokens, the app prompts users to start a new conversation and highlights the top entry point
- [Improved] Optimized action layout and spacing in the message area, making actions like copy/share/regenerate/resume more centralized and clearer
- [Improved] Improved interaction feedback and tooltip copy in the branch switcher for more intuitive branch navigation
- [Improved] Refined visual details of the input bar, message bubbles, and bottom status area for smoother reading and operation
- [Fix] Fixed and optimized the display/refresh flow of the state panel and log panel to reduce abnormal UI rendering issues
- [Fix] Fixed several minor UI issues
