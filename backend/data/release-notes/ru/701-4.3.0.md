## 4.3.0

- [Новое] Добавлен локальный OpenAI-совместимый API-сервер, который позволяет подключать модели RWKV через стандартный API (только для платформ Windows / macOS / Linux)
- [Новое] В API-сервер встроена панель управления, где можно просматривать журналы запросов, запускать тестовые диалоги и знакомиться с документацией по API
- [Новое] Добавлена поддержка NPU-ускорения для Snapdragon 8 Gen 5 (Snapdragon 8gen5)
- [Новое] Добавлена поддержка весов RWKV7-G1e 2.9B для бэкенда QNN
- [Улучшено] Расширены и улучшены предустановленные подсказки (в данный момент только для упрощённого китайского; поддержка других языков будет добавлена позже)
- [Улучшено] Улучшен внешний вид UI для предустановленных подсказок
