## 4.8.0

- [신규] Android, Windows(x64 / ARM64), Linux용 4.8.0(빌드 755) 패키지를 Hugging Face, ModelScope, GitHub에 배포했습니다. 이전 4.8.0을 설치했다면 새 패키지를 받아 다시 설치해 주세요
- [개선] G1j GGUF의 기존 양자화 설정을 유지합니다. 1.5B는 Q6_K를, 2.9B, 7.2B, 13.3B는 Q4_K_M을 사용합니다
- [수정] Huawei DroiTong에서 대형 모델 전환 시 종료되는 문제와 긴 대화 후 로그를 읽을 때 채팅이 중단되는 문제를 수정했습니다
- [수정] Android 텍스트 채팅에서 사고 종료 표시를 완전히 인식하지 못하거나 빠른 사고 모드의 답변 본문이 표시되지 않는 문제를 수정했습니다
- [수정] G1j 1.5B 및 2.9B PALM CPU 모델을 W8 가중치로 변경하여 기존 W4 경로에서 질문을 반복하거나 정상적으로 답변하지 못하는 문제를 해결했습니다. 설치 후 모델 목록에서 PALM 모델을 다시 다운로드해 주세요

- [수정] [Android 4.8.0 채팅 수정 APK 다운로드 (Huawei DroiTong 포함)](https://modelscope.cn/datasets/HaloWang1991/rwkv-chat/resolve/8f100f24620e128a41c314a39ed97b5954488a12/android-arm64/rwkv_chat_4.8.0_755.apk)

- [신규] RWKV7-G1j 1.5B, 2.9B, 7.2B, 13.3B 모델 지원을 추가했습니다. 사용 가능한 모델과 다운로드 출처는 현재 기기의 모델 목록에서 확인할 수 있습니다
- [신규] PALM CPU 추론 백엔드 추가
