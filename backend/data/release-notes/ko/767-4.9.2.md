## 4.9.2

- [수정] iPhone과 macOS에서 대용량 모델을 압축 해제할 때 앱이 종료될 수 있는 문제를 수정했습니다.
- [수정] macOS 설치 창에 응용 프로그램 폴더 바로가기를 복원했습니다.

## 4.9.1

- [신규] 채팅에서 더 많은 웹 검색 서비스를 지원합니다. 메시지 입력란 옆에서 검색을 켜거나 서비스를 바꿀 수 있습니다.
- [개선] 답변에서 출처 링크를 열거나 검색 세부정보를 펼쳐 검색어와 결과를 확인할 수 있습니다.
- [개선] 모델 목록의 G1 세대 표시를 더 명확하게 바꿔 버전을 쉽게 구분할 수 있습니다.

## 4.9.0

- [개선] macOS에서 일부 모델의 생성 및 긴 프롬프트 처리 속도를 개선했습니다.
- [개선] Windows의 CPU 추론 성능과 CUDA 실행 안정성을 개선했습니다.
- [개선] 일부 Android 기기의 CPU 생성 속도를 높이고 모델 전환 시 리소스 해제를 개선했습니다.
- [개선] 생성 중 불필요한 화면 갱신을 줄여 더 부드럽게 조작할 수 있습니다.
- [수정] 모델을 불러온 뒤 화면의 샘플링 설정과 실제 생성 매개변수가 일치하지 않는 문제를 수정했습니다.
