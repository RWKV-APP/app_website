## 4.9.0

- [개선] macOS에서 일부 모델의 생성 및 긴 프롬프트 처리 속도를 개선했습니다.
- [개선] Windows의 CPU 추론 성능과 CUDA 실행 안정성을 개선했습니다.
- [개선] 일부 Android 기기의 CPU 생성 속도를 높이고 모델 전환 시 리소스 해제를 개선했습니다.
- [개선] 생성 중 불필요한 화면 갱신을 줄여 더 부드럽게 조작할 수 있습니다.
- [수정] 모델을 불러온 뒤 화면의 샘플링 설정과 실제 생성 매개변수가 일치하지 않는 문제를 수정했습니다.
- [수정] 같은 크기와 추론 엔진의 호환되는 새 모델을 사용할 수 있으면 대체된 이전 모델을 숨깁니다.
