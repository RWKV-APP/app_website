## 4.2.0

- [신규] `RWKV가 질문해 드려요` 기능을 추가했습니다. 현재 대화 문맥과 질문 접두어를 바탕으로 바로 보낼 수 있는 질문을 하나 이상 자동 생성할 수 있습니다
- [신규] `RWKV가 질문해 드려요`는 다국어 질문 접두어와 일괄 생성을 지원하여 더 빠르게 대화를 시작할 수 있도록 돕습니다
- [신규] macOS에서 RWKV7-G1e 7.2B의 MLX 가중치를 지원합니다
- [개선] 원격 설정과 네트워크 요청 URL 구성 로직을 재구성하여 업데이트 정보, 릴리스 노트, 추천 문구 가져오기가 더 안정적으로 동작합니다
- [개선] 입력 바 상호작용 구조를 조정하고 이미지 및 음성 페이지의 추천 영역 시각 표현을 개선했습니다
- [개선] 모바일에서는 모델이 답변을 생성하거나 가중치를 다운로드하는 동안 화면이 자동으로 켜진 상태로 유지되어 작업 중단을 줄입니다
- [수정] 일부 페이지 정보가 중복 표시되던 문제를 수정했습니다
- [수정] 여러 UI 세부 문제를 수정했습니다
