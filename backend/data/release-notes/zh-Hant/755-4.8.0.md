## 4.8.0

- [新增] 發布 Android、Windows（x64 / ARM64）和 Linux 的 4.8.0（build 755）安裝套件，可從 Hugging Face、ModelScope 和 GitHub 下載；若已安裝早期 4.8.0，請重新下載安裝
- [優化] G1j GGUF 維持既定量化：1.5B 使用 Q6_K，2.9B、7.2B 和 13.3B 使用 Q4_K_M
- [修復] 修復華為卓易通切換大型模型時退出，以及長時間聊天後讀取日誌導致聊天中斷的問題
- [修復] 修復 Android 文字聊天中思考結束標記識別不完整、快速思考無法顯示正文的問題
- [修復] G1j 1.5B 和 2.9B 的 PALM CPU 模型改用 W8 權重，修復舊 W4 路徑重複提問、無法正常回答的問題；安裝後請在模型清單重新下載 PALM 模型

- [修復] [下載 Android 4.8.0 聊天修復版（含華為卓易通）](https://modelscope.cn/datasets/HaloWang1991/rwkv-chat/resolve/8f100f24620e128a41c314a39ed97b5954488a12/android-arm64/rwkv_chat_4.8.0_755.apk)

- [新增] 新增 RWKV7-G1j 1.5B、2.9B、7.2B 和 13.3B 模型支援；實際可用模型及下載來源以目前裝置的模型清單為準
- [新增] 新增 PALM CPU 推論後端
- [優化] 根據目前裝置的執行環境支援顯示可用推論後端
